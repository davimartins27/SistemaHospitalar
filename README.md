# Sistema Hospitalar — Trabalho Prático

Projeto desenvolvido para a disciplina de Programação Modular.

## Sprint 1
Front-end estático com telas de pacientes, profissionais, consultas, internações, quartos e histórico médico.

## Sprint 2
API REST com Java 17, Spring Boot, Spring Data JPA e MySQL. A implementação está na pasta `backend`.

## Como visualizar o front-end
Abra o arquivo `index.html` no navegador ou use o Live Server do VS Code.

## Como executar a API
Veja as instruções em [`backend/README.md`](backend/README.md).

## Documentação
Os diagramas e documentos estão na pasta `documentos`.
